iGhostVT 1.3.3 makes pasting a screenshot into a remote tab work like dropping one, and the New Tab menu now shows each device's terminals with the titles their tabs have.

- Pasting a screenshot, photo or copied file into a tab whose terminal runs on another device pasted a path on this device, which that terminal could not open. The paste now copies the file to the other device first, with the same progress bar as a drop, and pastes the path there. This works with ⌘V and with Paste in the edit menu. The Paste key on the keyboard bar still pastes a path on this device.
- The New Tab menu could list another device's terminals as they were up to half a minute earlier, including terminals already closed and checkmarks for tabs no longer open. The menu now asks the device when it opens.
- New Tab named another device's terminals by process and folder, so the names did not match what that device's tabs showed. Each terminal is now listed with the title its tab shows on that device, and the process below it.
- Each paired device now has its own submenu under Other Devices in New Tab, so a device's terminals no longer make the menu long.
- In Settings ▸ Remote Access, typing a name could stop working partway through, because a tab reconnecting behind Settings took over the keyboard. Settings now keeps the keyboard until you close it.
- In a windowed app on iPad, the window's red, yellow and green buttons covered the first line of the terminal and the sidebar title. Both now move clear of them.
- In a narrow window or on iPhone, the file transfer bar now appears at the bottom centre, above the tab bar, instead of the middle of the terminal.
- Move to New Window is now hidden when it cannot be used, instead of shown greyed out.
- The tab bar on iPad now lays out and scrolls tabs the same way as on the Mac: tabs share the full width and scroll once each is narrower than 200 points.
- Closing a remote tab now asks with Keep Running first, End Session second and Cancel last.
- The pairing screens are now centred vertically.
- In Settings, the accent colours now line up with the right edge of the row; the ring around the chosen colour opens out with a short animation.
- Large amounts of output reach the screen faster, especially on remote tabs.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, or `iGhostVT-1.3.3-macos.zip` for a Mac. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
