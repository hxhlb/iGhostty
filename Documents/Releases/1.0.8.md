iGhostVT 1.0.8 completes its access to the graphics processor, so iOS features that draw with it cannot close the app.

- iGhostVT already had graphics access for the terminal. iOS also draws app icons, Bold Text and the share sheet with the graphics processor, and a few of the pieces those need were missing. iGhostVT now asks for the same list as the other OwnGoal apps.
- Every package is now checked for that access before it is published, so a build without it is not released.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `xros-arm64e` for an Apple Vision Pro running custom firmware, or `iGhostVT-1.0.8-macos.zip` for a Mac — the Mac app is ad-hoc signed, so clear its quarantine once with `xattr -dr com.apple.quarantine /Applications/iGhostVT.app`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
