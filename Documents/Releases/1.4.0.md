iGhostVT 1.4.0 can reach your devices away from the local network through a relay you run yourself, and the touch edit menu now follows your language.

- A paired device could be reached only when both were on the same network. Run the relay from `Relay/compose.yml` on any Linux server, open the `.vtrpsc` file it writes on each device, and every device that has it can reach the others from anywhere. The connection stays encrypted from end to end, and the relay never sees what passes through it. On the local network the app still connects directly.
- Devices that both use the relay can now be paired through it, not only on the same network. Settings ▸ Remote Access shows a Relay section only once a relay is set up.
- Remote Access settings listed devices you had paired together with devices you had not. Devices not yet paired are now in a separate Other Devices section, and the two lists are named Authorized Devices (may open terminals here) and Accessible Devices (this device can open terminals on them). On the Mac each list opens in a sheet of its own.
- Two devices on different versions of iGhostVT could connect and then misbehave. They now refuse to connect, the other device shows as Needs Update in New Tab, and Settings says which version each one runs. Update both to 1.4.0.
- A remote tab could stay frozen for a long time after the network dropped. Remote tabs now notice a dead connection within a minute and reconnect to the same session.
- Tapping a locked tab did nothing, with no hint why. The lock caption now appears again on each tap.
- Copy, Paste, Select and Select All in the touch edit menu were always in English. They now follow the system language, and on iOS 17 and later a loupe shows what is under your finger while you move a selection handle.
- Alerts used up to three different button colours. Every alert now has at most one highlighted button.
- On iPhone and iPad with a high refresh rate display, the terminal now scrolls and animates at up to 120 Hz.
- The tab that is active in the Lock Screen widget is no longer shown in bold.
- Choosing Custom… for the default shell left the menu reading Automatic. It now reads Custom, and an empty path goes back to Automatic.
- Turning off Remember Directories now also clears the remembered list; the separate Clear button is gone.
- The terminal on the Mac now starts at 12 points instead of 14. A size you set yourself is kept.
- The Mac app no longer offers Open and Open Recent in the File menu, and macOS no longer quits it on its own to reclaim memory, which could leave idle shells running.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, or `iGhostVT-1.4.0-macos.zip` for a Mac. To run the relay, use the attached `compose.yml`; the image is `ghcr.io/owngoal-dev/ighostvt-relay`, and the digest is in `relay-image.txt`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
