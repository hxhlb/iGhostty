iGhostVT 1.4.5 keeps the accessory keys with the onscreen keyboard while a hardware keyboard is connected, and ships the Mac app signed and notarized; it connects to devices on any 1.4 release.

- With Hide with Hardware Keyboard on, the accessory keys disappeared whenever a keyboard was connected, even while you typed on the onscreen keyboard with a keyboard case folded back. They now stay down only while you type on the hardware keyboard and come back with the onscreen keyboard — on iPadOS 17 and later, the floating keyboard too.
- After you changed the terminal text size in Settings, changing the theme, or the system switching between light and dark, resized terminals that were already open. They now keep the size they had.
- The Mac app had to have its quarantine cleared before it would open. Each release now also has a copy signed with Developer ID and notarized by Apple, which opens like any other app.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, or `iGhostVT-1.4.5-macos-notarized.zip` for a Mac — it is signed and notarized, so it opens without clearing quarantine. To run the relay, use the attached `compose.yml`; the image is `ghcr.io/owngoal-dev/ighostvt-relay`, and the digest is in `relay-image.txt`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
