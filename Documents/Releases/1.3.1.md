iGhostVT 1.3.1 closes security holes in the terminal helper, remote access, and dropping files on the Mac.

- On a device running custom firmware, a program running as `mobile` could plant links in the helper's log folder and have the helper overwrite or add to any file as root. The helper now refuses to follow such links and only writes to files it created itself.
- Any program running as `mobile` could turn remote access on by creating a file. The switch now lives where only root can write, so only the app can turn it on. If you already had it on, it stays on after the upgrade.
- A device on the local network that had never paired could make the host's remote-access helper use hundreds of megabytes before it was turned away. A connection that has not paired is now limited to small messages.
- On the Mac, dropping a file whose name contained a line break typed the rest of the name at the prompt, where a shell could run it as a command. Such a file is now pasted as a copy with the line break removed from its name.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, or `iGhostVT-1.3.1-macos-notarized.zip` for a Mac — it is signed and notarized, so it opens without clearing quarantine. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
